# Memory Representation Study

研究长期记忆的组织形式如何影响模型使用已经召回的证据。

当前仓库只记录研究问题与可执行协议。尚未完成数据审计或模型实验，所有假设均为 `NOT_PROVEN`。

## 当前问题

> 当事实记录完全相同时，按时间平铺事实，或按“实体—属性”组织为版本链，这两个完整序列化方案会怎样影响同一模型家族不同规模模型的工具参数绑定？

首轮估计两个完整序列化方案的总效应。正确事实由 Oracle Evidence 给定，避免把检索召回与模型使用证据混在一起；具体结构机制留给后续消融。

## 第一篇文档

- [研究方向 001：平铺事实与版本链如何影响不同规模模型使用长期记忆](docs/001-memory-representation-and-reader-capacity.md)

## 当前执行顺序

1. 审计 Mem2ActBench 的公开数据能否确定性生成两种信息等价的表示。
2. 复现固定样本上的上游 Oracle Evidence 评分流程。
3. 发布 v1.0 预注册，冻结样本、转换、评分和统计协议后再运行正式实验。

若第一步失败，仓库将发布 `BLOCKED` 结果和反例，不用不可归因的实验填补结论。

## 原则

- 一次实验只改变一个 owning layer。
- 不截断 gold facts，也不静默排除失败输出。
- 主指标使用确定性评分，公开运行 manifest 和 null result。
- 结论只覆盖实际测试的数据、表示与模型规模。
